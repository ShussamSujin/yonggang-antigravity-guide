1. **0단계 ~ 7단계 단계별 실습 로드맵**:
   - 0단계: 사전 준비 (Antigravity, Node.js, Git, Netlify 다운로드 및 가스레인지/타임머신 비유)
   - 1단계: 안티그래비티 작업실 세팅 & 울타리 치기
   - 2단계: Google AI Studio 무료 API 키 발급 & 보안 수칙 (현관 열쇠 비유)
   - 3단계: 마법의 4칸 공식 & 연수 실습 핵심 프롬프트 원클릭 복사
   - 4단계: 내 컴퓨터(localhost) 미리보기 & Git 커밋 안전장치
   - 5단계: Netlify 무료 배포 & 증상별 처방전
   - 6단계: 클라우드 & 결제 안심 이야기 (100% 무료 범위, 패턴 B 연동법)

## 🚀 깃허브(GitHub) 리포지토리 및 무료 웹 배포(GitHub Pages) 방법

이 사이트를 선생님의 깃허브에 올리고 전 세계 어디서나 접속할 수 있는 인터넷 링크(`https://아이디.github.io/리포지토리명`)로 만드는 초간단 3단계입니다:

### 1단계: GitHub에서 새 저장소(New Repository) 만들기
1. [GitHub](https://github.com)에 로그인합니다.
2. 오른쪽 위 **[+]** 버튼 클릭 → **[New repository]** 선택
3. **Repository name**에 `yonggang-antigravity-guide` (또는 원하는 이름) 입력
4. **Public** 선택 후 맨 아래 초록색 **[Create repository]** 버튼 클릭

### 2단계: 터미널에서 깃허브로 업로드(Push)
안티그래비티 대화창이나 터미널에 아래 명령어를 실행합니다:
```bash
git branch -M main
git remote add origin https://github.com/선생님깃허브아이디/yonggang-antigravity-guide.git
git push -u origin main
```

### 3단계: GitHub Pages 켜기 (10초 무료 배포)
1. 깃허브 저장소 화면에서 상단 **[Settings]** 탭 클릭
2. 왼쪽 메뉴에서 **[Pages]** 클릭
3. **Branch** 설정에서 `None` → `main` 선택 후 **[Save]** 클릭
4. 1~2분 뒤 상단에 생성된 진짜 인터넷 주소가 표시됩니다:
   👉 `https://선생님아이디.github.io/yonggang-antigravity-guide/`
