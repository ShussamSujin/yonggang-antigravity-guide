2단계 : 서랍(폴더) 만들고 안티그래비티에 연결하기

앱 하나 = 폴더 하나! AI가 일할 서랍을 정해주고 울타리를 칩니다.

A 바탕화면에 새 폴더 만들기

1. 바탕화면 빈 곳 우클릭 → [새 폴더] 만들기
2. 폴더 이름을 quiz 로 정해주세요.

📁 바탕화면 → 📁 quiz
B 안티그래비티에서 폴더 열기

1. 안티그래비티 프로그램 실행
2. 왼쪽 위 [Add folder] (또는 폴더 열기) 클릭
3. 방금 만든 quiz 폴더 선택 후 [신뢰(Yes)] 클릭!

💡 이렇게 하면 AI가 이 quiz 폴더 안에서만 일하므로 컴퓨터의 다른 중요한 파일은 절대 건드리지 못해 안전합니다!

우리 앱 안에 똑똑한 Gemini AI를 넣기 위한 무료 신분증을 받아요.

1. 사이트 접속 aistudio.google.com 에 들어갑니다.

4. 복사해두기 화면에 나온 긴 영어 글자를 복사해서 메모장에 둡니다.
Google AI Studio 열기 (무료 키 받으러 가기)

4단계 : 마법의 주문서 복사해서 붙여넣기

가장 중요★

선생님이 직접 타자 치실 필요 없이, 아래 초록색 복사 버튼을 누르고 안티그래비티 대화창에 붙여넣기(Ctrl+V)만 하세요!

👉 아래 주문서를 복사해서 안티그래비티 대화창에 붙여넣으세요: 
중학교 2학년 학생이 쓰는 서술형 답안 연습 웹앱을 만들어줘.

[화면]
· 문제 하나, 답을 쓰는 칸, [피드백 받기] 버튼
· 학생이 크롬북(디벗)과 휴대폰으로 보니까 글씨 크게, 버튼 크게 해줘

[내용]
· 문제는 중2 기술·가정 '영양소' 단원 서술형 문항이야:
  "청소년기 성장을 위해 꼭 필요한 단백질과 칼슘의 체내 기능과 대표 급원 식품을 서술하시오."

[AI 기능]
· 버튼을 누르면 서버 함수가 Gemini API를 불러서 친절한 말투로 다음 피드백을 제공해줘:
  1) 잘한 점 2가지
  2) 보완할 점 2가지 (정답을 바로 주지 말고 다시 생각해볼 힌트로)
  3) 한 줄 총평 및 [결과 복사] 버튼

[API 키 보안]
· API 키를 코드에 절대 넣지 말고 서버 환경변수 GEMINI_API_KEY 로 읽어줘.
· 키는 서버 함수에서만 쓰고, 화면 쪽 코드에서는 절대 쓰지 마.
· 내 컴퓨터에서 시험할 수 있게 .env 예시 파일도 만들어줘.
· 키 값은 아직 비워두고, 내가 어디에 넣으면 되는지 알려줘.

[배포 준비]
· Netlify에 올릴 거니까 서버 함수는 netlify/functions 폴더에 만들어줘.

[디자인]
· 달콤한 디저트 베이커리 파스텔톤 느낌으로 귀엽고 둥글둥글하게 꾸며줘.
· 학생 개인정보(이름·학번 등)는 절대 입력받거나 저장하지 마.

🧙 고치고 싶거나 막힐 때 쓰는 5가지 마법 문장 (원클릭 복사)

“방금 그거 되돌려줘”
“글씨 더 크게, 버튼 둥글게 해줘”
“초등학생도 알게 쉽게 설명해줘”
“브라우저로 직접 눌러보고 고쳐줘”

5단계 : 인터넷에 올리기 전에 내 컴퓨터에서 먼저 써보기

localhost는 '문 열기 전 나만의 시식 코너'입니다. 아무도 못 보니 편하게 테스트하세요!

🥐 확인하는 순서

  1. AI가 만든 .env 파일에 아까 발급받은 API 키를 붙여넣습니다.
  2. 안티그래비티 대화창에 “.env에 키 넣었어. 화면 보여줘” 라고 씁니다.
  3. 화면에 뜬 http://localhost:... 파란 링크를 누르면 크롬에서 내 앱이 열립니다!
  4. 답안을 아무렇게나 입력하고 [피드백 받기]를 눌러 잘 나오는지 봅니다.

📸 마음에 들면 타임머신 저장(커밋)하기

화면이 마음에 들면 언제든 이 상태로 돌아올 수 있게 저장해 두세요:

6단계 : 무료로 인터넷에 올리고 진짜 주소 받기 (배포)

내 컴퓨터를 꺼도 학생들이 언제든 접속할 수 있는 인터넷 주소가 생깁니다!

🚀 배포 요청 주문서 복사: 
이 앱을 Netlify에 무료로 배포해줘.
Netlify CLI를 설치해서 진행하고, 로그인이 필요하면 알려줘.
Gemini API 키는 Netlify 환경변수 GEMINI_API_KEY 로 안전하게 등록해서 올려줘.
1. AI가 자동 설치: 알아서 배포 준비를 합니다 (1분).
2. 브라우저 승인: 화면에 뜬 창에서 [Authorize]만 클릭!
3. 주소 획득: https://앱이름.netlify.app 완료!

8단계 : 수업에 쓰기 전 필수! 학운위 심의 3분 가이드

필수 절차

2026학년도부터 모든 학생용 앱은 학교운영위원회 심의를 거쳐야 안전합니다!

⚠️ “개인정보를 안 받는데도 심의를 받아야 하나요?”

네, 맞습니다! 학생 이름이나 학번을 안 받더라도 ‘학습 내용(문제와 해설)’이 들어있으면 교재로서 학교운영위원회 심의 대상이 됩니다. (선생님을 보호하기 위한 장치예요!)

📋 AI에게 심의 서류(개인정보 처리방침) 써달라고 시키기:

내가 방금 만든 웹앱의 학운위 심의 제출용 '개인정보 처리방침' 초안을 써줘.
· 학생 이름, 학번, 로그인은 전혀 받지 않고 아무것도 저장하지 않아.
· 학생이 쓴 답안 텍스트만 Google Gemini AI로 전송되어 피드백을 받아.
· 쿠키나 광고는 없어.
선생님이 바로 제출할 수 있게 11개 조항에 맞춰 깔끔하게 정리해줘.

어려운 컴퓨터 말을 세상에서 제일 쉬운 비유로 바꿨어요.

            

          

        


        

          

            바이브 코딩
            
원하는 분위기와 기능을 말로 주문하면 AI가 코드로 만들어주는 개발 방식

          


          

            배포 (Deploy)
            
‘가게 문 열기’. 내 컴퓨터에만 있던 파일을 인터넷에 올려 주소(URL)를 만드는 일

          


          

            localhost
            
‘문 열기 전 나만의 시식 코너’. 남들은 못 보고 나만 볼 수 있는 임시 주소

          


          

            API 키
            
‘AI 부르는 무료 열쇠’. 현관 비밀번호 같아서 남에게 보이지 않게 서버에 숨겨둡니다

          


          

            Git 커밋
            
‘타임머신 찰칵 저장’. 망쳤을 때 1초 만에 정상 상태로 돌아올 수 있는 안전장치

          


          

            서버 (Server)
            
‘주방’. 손님이 답을 쓰면 AI에게 물어보고 피드백을 만들어 내놓는 보이지 않는 공간
