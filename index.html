마법의 4칸 공식 & 실습 프롬프트 복붙

복사 버튼 하나로 끝! 연수 교안 속 핵심 실습 문장을 그대로 담았습니다.

🍓 바이브 코딩 요청 문장 4칸 공식

① 무엇을 중2 가정 영양소 서술형 연습 도우미 웹앱을
② 어떻게 생긴 문제 하나씩 보여주고 [피드백 받기] 버튼으로
③ 누가 쓰는 학생이 크롬북과 휴대폰으로 편하게 쓰도록
④ 어떤 느낌으로 디저트 베이커리 감성 파스텔톤으로 깔끔하게

🌟 오늘 연수 실습 핵심 프롬프트 (그대로 복사!) 

중학교 2학년 학생이 쓰는 서술형 답안 연습 웹앱을 만들어줘.

[화면]
· 문제 하나, 답을 쓰는 칸, [피드백 받기] 버튼
· 학생이 크롬북(디벗)과 휴대폰으로 보니까 글씨 크게, 버튼 크게 해줘

[내용]
· 문제는 중2 기술·가정 '영양소' 단원 서술형 문항이야:
  "청소년기 성장을 위해 꼭 필요한 단백질과 칼슘의 체내 기능과 대표 급원 식품을 서술하시오."

[AI 기능]
· 버튼을 누르면 서버 함수가 Gemini API를 불러서 친절한 말투로 다음 피드백을 제공해줘:
  1) 잘한 점 2가지
  2) 보완할 점 2가지 (정답을 바로 주지 말고 다시 생각해볼 힌트로)
  3) 한 줄 총평 및 [결과 복사] 버튼

[API 키 보안]
· API 키를 코드에 절대 넣지 말고 서버 환경변수 GEMINI_API_KEY 로 읽어줘.
· 키는 서버 함수에서만 쓰고, 화면 쪽 코드에서는 절대 쓰지 마.
· 내 컴퓨터에서 시험할 수 있게 .env 예시 파일도 만들어줘.
· 키 값은 아직 비워두고, 내가 어디에 넣으면 되는지 알려줘.

[배포 준비]
· Netlify에 올릴 거니까 서버 함수는 netlify/functions 폴더에 만들어줘.

[디자인]
· 달콤한 디저트 베이커리 파스텔톤 느낌으로 귀엽고 둥글둥글하게 꾸며줘.
· 학생 개인정보(이름·학번 등)는 절대 입력받거나 저장하지 마.

🧙 막혔을 때 외워두면 평생 쓰는 마법의 5문장

① “방금 그거 되돌려줘”
② “오류 났어. 화면에 이렇게 떠: (내용)”
③ “초등학생도 알 수 있게 설명해줘”
④ “브라우저로 눌러보고 고쳐줘”
⑤ “지금 상태 저장해줘 (Git 커밋)”

개인정보 보호법 제30조 및 개인정보보호위원회 작성지침의 11개 조항 구성을 따라줘.

· 이 앱은 이름·학번·로그인을 일체 받지 않고, 아무것도 저장하지 않아.
· 학생이 작성한 답안 텍스트만 피드백 생성을 위해 Google Gemini API로 전송돼.
· Netlify에 배포했고 서버 함수가 거기서 돌아.
· 쿠키, 광고, 외부 추적 도구는 일체 쓰지 않아.
· 보호책임자 성명 및 연락처는 빈칸으로 두고 내가 채울 곳을 표시해줘.
· 학운위 제출용으로 깔끔하게 작성해줘.

✨ 심의를 단번에 통과하는 교사 앱 제작 6대 원칙

1. 개인정보 0: 이름, 학번 일체 수집 금지 (만 14세 미만 동의 문제 해결)
2. 저장 0: 새로고침하면 답안이 사라지게 설계
3. 로그인 없음: 링크로 누구나 바로 진입
4. 문항 출처 기재: 교과서 몇 쪽/어느 단원인지 명시
5. 교사 사전 검수: AI가 낸 문제는 선생님이 꼭 확인
6. 전송 사실 고지: Gemini API로 전송됨을 문서에 명시

            바이브 코딩
            
Vibe Coding

            
원하는 분위기와 기능을 말로 설명하면 AI가 알아서 코드를 써주는 2025년 이후의 신개념 개발 방식

          


          

            서버 (Server)
            
인터넷에 켜진 남의 컴퓨터

            
‘주방’ 역할을 하는 컴퓨터. 손님이 주문하면 AI 채점이나 데이터 저장을 수행해 다시 내보내 줍니다.

          


          

            배포 (Deploy)
            
가게 문 열기

            
내 컴퓨터 안에만 있던 파일을 인터넷에 올려 전 세계 누구나 접속할 수 있는 주소(URL)를 만드는 일

          


          

            localhost
            
문 열기 전 가게 (나만 보기)

            
내 컴퓨터 안에서만 임시로 열리는 테스트 주소. 망가뜨려도 아무도 못 보니 안심하고 테스트하세요.

          


          

            Git / 커밋
            
무한 되돌리기 타임머신

            
지금 상태를 한 번 찰칵 저장해 두는 장치. 나중에 망쳐도 1초 만에 정상 상태로 돌아올 수 있습니다.

          


          

            API 키
            
현관문 비밀번호

            
Gemini AI에게 피드백을 부탁할 때 필요한 신분증. 코드나 학생 화면에 노출되지 않게 경비실에 보관합니다.
